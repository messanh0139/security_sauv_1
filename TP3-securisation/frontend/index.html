Pourquoi les injections échouent ?
Les requêtes préparées transmettent les paramètres séparément du SQL. Le driver psycopg2 échappe toute valeur passée via %s : les guillemets et mots-clés SQL sont traités comme du texte brut, jamais comme du code.
